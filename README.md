\# 🦸‍♀️ Classificador de Nível de Herói



Projeto desenvolvido como parte de um desafio da \*\*DIO\*\*, com o objetivo de praticar lógica de programação utilizando JavaScript.



\## 📌 Desafio

Criar um programa que classifique o nível de um herói com base na sua quantidade de experiência (XP).



\## 🛠️ Tecnologias Utilizadas

\- JavaScript



\## 📂 Estrutura do Projeto

\- `index.js`: contém a lógica de classificação do herói



\## ▶️ Como executar

1\. Instale o Node.js (caso não tenha)

2\. No terminal, execute:

```bash

node dio.js
